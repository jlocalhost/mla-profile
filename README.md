# RJ MLA Profile Dashboard

Advanced Full-Stack Monorepo built with Next.js 16, Turbo, and Tailwind 4.

## Structure
- `apps/web`: Next.js 16 Full Stack App
- `packages/ui`: Shared UI library (Tailwind 4 + React 19)
- `packages/db`: Prisma ORM + PostgreSQL
- `packages/config`: Shared configurations
- `packages/utils`: Shared utilities

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```

## Stack
- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- GSAP
- Prisma
- PostgreSQL
